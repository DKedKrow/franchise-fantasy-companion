# Security policy

## Reporting a vulnerability

Please do not post security vulnerabilities, private Franchise data, or save files in a public issue.

Use GitHub's private vulnerability reporting page:

https://github.com/DKedKrow/franchise-fantasy-companion/security/advisories/new

Include the app version, Windows version, a concise reproduction, and whether the issue could expose or modify local data. Do not attach a Madden `CAREER-` file. A privacy-safe support report generated by the app is acceptable after reviewing its contents.

## Supported versions

During the public beta, only the newest beta receives security fixes.
