# Franchise Fantasy Companion changelog

## 0.17.0-beta.1

- Renamed the public application to Franchise Fantasy Companion while preserving existing private-beta data.
- Published the first public beta as both a Windows installer and portable executable.
- Added an original application icon and consistent release branding.
- Reworked the first-run experience for new users and added privacy and independence disclosures.
- Added public installation, troubleshooting, data-safety, and verification documentation.

## 0.16.0

- Added Fantasy HQ with weekly RedZone leaders, spotlight games, NFL power rankings, head-to-head history, alerts, and a season magazine.
- Expanded the record book with rushing touchdowns, defensive interceptions, tackles, and largest wins.
- Added player-profile timelines and saved custom fantasy scoring.
- Added optional draft clocks plus pause, resume, and undo controls.
- Made fantasy-world managers retain moods, recent matchup memories, and evolving relationships.

## 0.15.0

- Added onboarding, compatibility health, global search, settings, backup/restore, diagnostics, recap pagination, and commissioner controls.
